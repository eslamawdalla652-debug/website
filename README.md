# 💳 Smart Budget Tracker (مدير المصاريف الذكي)

تطبيق ويب تفاعلي مصمم بـ **React.js** و **Tailwind CSS** لإدارة وتتبع المصروفات والإيرادات الشخصية اليومية بكل احترافية.

## ✨ المميزات والخصائص (Features)
- **إدارة الحالة (State Management):** تمرير البيانات والتحكم بها بكفاءة عالية بين المكونات (Component Architecture).
- **العمليات الأساسية (CRUD Operations):** إمكانية إضافة معاملات جديدة، حذفها، وحساب الرصيد الصافي أوتوماتيكياً.
- **التخزين المحلي (LocalStorage):** الحفاظ على البيانات وحفظها في متصفح المستخدم لضمان عدم ضياعها عند إعادة تحميل الصفحة.
- **البحث والفلترة (Search & Filter):** تصفية المعاملات بسهولة بين الإيرادات والمصروفات أو البحث بالعنوان والتصنيف.
- **تصميم عصري (Responsive UI):** واجهة مستخدم مظلمة (Dark Mode) وأنيقة متوافقة مع جميع الشاشات.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **React.js** (Functional Components, Hooks: `useState`, `useEffect`)
- **Tailwind CSS** (للتصميم والتنسيق العصري)
- **JavaScript (ES6+)**
